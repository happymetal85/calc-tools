## 보는 방법

**공개 링크** — 저장소 설정에서 GitHub Pages를 켜면 `https://<계정>.github.io/<저장소>/` 로 열립니다.

**내 컴퓨터에서** — 파일을 내려받아 아래를 실행하고 `http://localhost:8790/` 에 접속합니다.

```
py -3 -m http.server 8790
```

`index.html` 을 두 번 눌러 바로 열어도 대부분 동작하지만, 브라우저 보안 정책 때문에 일부 기능은 위처럼 서버로 여는 편이 안전합니다.

## 만든 방식

- **의존성 없음** — 프레임워크·번들러·패키지를 쓰지 않습니다. `index.html` 이 `js/core.js` 와 `js/calculators/*.js` 를 순서대로 읽고, 각 파일이 `HT.register({...})` 로 자기 자신을 등록합니다.
- **주소로 이동** — `#/계산기id` 해시 라우터. 링크를 그대로 공유할 수 있습니다.
- **값 이어받기** — 재무 대시보드에 한 번 넣은 소득·자산·대출을 다른 계산기가 초기값으로 씁니다. 저장은 브라우저 안에서만 이뤄집니다.
- **결과 공유** — 백분위·성향 같은 도구는 결과 문장 복사와 1080×1080 이미지 카드 저장을 지원합니다.
- **디자인** — 코웨이엔텍 Tide 팔레트와 Gothic A1·Noto Sans KR. 평소엔 회색, 문제가 있는 곳에만 색을 씁니다.

계산기를 하나 더하려면 `js/calculators/` 에 파일을 만들고 `index.html` 에 `<script>` 한 줄을 넣으면 됩니다. 자세한 규칙은 [한손도구 README](한손도구/README.md)에 있습니다.

## 기준 시점과 한계

2026년 9월 5일 시행 중인 법령·요율로 검증했습니다. 국민연금 요율 9.5%, 건강보험 7.19%, 기준금리 3.00%, 10·15 대책 대출 규제 등이 들어 있습니다. 발표는 됐지만 시행 전인 세제·지방세제 개정안은 계산기 안에서 **현행 / 개정안** 으로 나누어 전환해 볼 수 있습니다.

- 세금·대출 결과는 추정치입니다. 실제 신고와 심사는 개별 요건을 따르니 최종 확인은 세무사·금융기관에서 하세요.
- 아파트 실거래가 조회는 국토교통부 공공데이터 인증키와 `한손도구/tools/proxy.js`(Node) 중계가 있어야 동작합니다. 키는 저장소에 없습니다.
- 운세·궁합·타로·돈 성향은 재미로 보는 것입니다.
- 음력·절기표는 1900~2049년 범위입니다.
