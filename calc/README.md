# 숫자맛집 계산기 모음

집·급여·세금·노후를 숫자로 확인하는 계산기를 순수 HTML/CSS/JS로 만든 프로젝트입니다.
빌드 도구나 서버 없이 `index.html`을 브라우저에서 열면 바로 동작합니다.

## 실행

```
index.html 을 더블클릭 (Chrome·Edge 권장)
```

인터넷이 연결되어 있으면 웹 글꼴(Gothic A1·Noto Sans KR)과 아래 온라인 기능이 함께 동작하고,
오프라인이면 시스템 글꼴로 대체되며 계산기는 모두 그대로 쓸 수 있습니다.

## 구성

```
index.html                 진입점 — 계산기 스크립트를 모두 불러온다
css/tokens.css             코웨이엔텍 Tide 디자인 토큰 (라이트·다크)
css/app.css                레이아웃·컴포넌트 스타일
js/core.js                 공통 코어: 숫자 서식, 누진세, 입력 폼, 결과 패널, SVG 차트, 라우터
js/calculators/*.js        계산기 1개 = 파일 1개 (단위변환기 7종은 unit-converters.js 하나)
tools/proxy.js             아파트 실거래가 조회용 로컬 프록시 (Node)
```

계산기는 `HT.register({ id, cat, name, desc, note, render(root) })` 로 등록합니다.
새 계산기를 추가하려면 파일을 만들어 `index.html`에 `<script>` 한 줄을 넣으면 됩니다.

## 내 집 마련 시뮬레이터

연봉·자기자본 → 실수령액 → 대출 한도(DSR 40% + 스트레스 금리, LTV, 집값별 절대한도) → 살 수 있는 최대 집값(이분 탐색) → 부대비용(취득세·생애최초 감면·중개보수·국민주택채권 할인·인지세·등기·법무사·이사) → 월 상환 부담 판정 → 연간 보유세(재산세+종부세)를 한 화면에서 계산합니다.
"세제 기준"을 개정안으로 바꾸면 2026년 세제개편안(종부세 실거주 1주택 공제 14억, 공정시장가액비율 70%, 2027년 세율표)과 지방세제 개편안(생애최초 감면 연장·청년 300만원, 재산세 특례 2029년 연장)을 적용합니다. 보유세는 현행·개정안 두 열을 항상 함께 보여줍니다.

## 전세 · 월세 · 반전세 비교

탭 1은 전세·반전세·월세의 월 실질 비용(전세대출 이자, 보증금 기회비용, 보증보험료, 월세, 월세 세액공제, 전세대출 원리금 소득공제)을 표로 비교하고 환산 전세가로 같은 잣대에 놓습니다.
탭 2는 지금 사는 전세를 반전세로 바꿀 때 법정 전환율(기준금리 3.00% + 2%p = 5.0%)에 따른 상한 월세, 집주인 제시 월세의 적정성, 갱신 시 5% 인상 상한 초과 여부, 전환 전후 월 부담과 손익분기 전환율을 계산합니다. 시세를 넣으면 전세가율과 HUG 반환보증 가입 가능 여부도 점검합니다.
탭 3은 집주인이 보증금 인상을 요구할 때 A안(증액분 대출로 전세 유지)·B안(증액분을 월세로 전환)·C안(이사: 중개보수·이사비 포함)의 2년 총 추가 비용을 비교하고 5% 상한·법정 전환율 초과 여부를 표시합니다.

## 대출 갈아타기 손익 시뮬레이터

기존 대출(잔액·금리·잔여기간·상환방식·경과 개월)과 새 대출(금리·기간·상환방식)을 넣으면 중도상환수수료(3년 이내 잔여기간 비례)·인지세·부대비용을 뺀 순 손익을 "보유 예정 기간 동안 낸 돈 + 그 시점 남은 원금" 기준으로 비교합니다. 손익분기 시점(개월), 손익분기 금리, 월별 누적 손익 그래프, 연도별 표를 제공합니다.

## 조기상환 시뮬레이터

매달 추가 납입 또는 목돈 일시 상환(매년 반복 가능)이 이자와 만기를 얼마나 줄이는지 월 단위로 시뮬레이션합니다. 상환 후 "기간 단축 / 월 납입 감소"를 고를 수 있고, 3년 이내 상환분에 붙는 중도상환수수료(연 10% 면제 한도 반영)를 뺀 순 절감액을 같은 돈을 예금(세후)했을 때의 이자와 비교해 판정합니다.

## 1억 만들기 시뮬레이터

연봉·나이·지출을 넣으면 실수령액(중소기업 청년 소득세 감면 반영)에서 저축 여력을 구하고, 청년미래적금(월 50만·3년·기여금 6/12%·비과세) → 청년 주택드림 청약(4.5%·비과세) → ISA(납입 4천만·비과세 500/1,000만) → 일반 예적금 또는 투자 순으로 배분하는 세 전략(예적금만 / 정책상품 풀활용 / 정책상품 + 투자)의 목표 도달 기간을 비교합니다. 첫 달 실행 계획, 목표 기간 역산(월 저축 필요액), 민감도(지출 절감·연봉·수익률·초기자산 변화)를 함께 보여줍니다. 상품 조건은 2026년 9월 기준입니다.

## 은퇴 시뮬레이터 · 자녀 증여 플래너 · 매수 vs 전세+투자

- **은퇴 시뮬레이터(FIRE)**: 현재 자산·월 저축·실질 수익률·은퇴 후 생활비에 2026년 개혁 국민연금 산식(비례상수 1.29, A값 3,193,511원, 출생연도별 수급개시연령)을 더해 목표 나이 은퇴 시 자산 소진 여부, 가장 빠른 은퇴 나이, 4% 룰 필요 자산, 민감도 7가지를 계산합니다.
- **자녀 증여 플래너**: 10년 단위 공제(미성년 2천만·성년 5천만)와 혼인·출산 공제 1억을 회차별로 배분하고 10년 합산 과세를 적용해 분할 증여 총세금을 일시 증여와 비교합니다. 조부모 세대생략 할증(30%), 증여 자산의 자녀 명의 운용 수익도 반영합니다.
- **매수 vs 전세+투자**: 같은 자기자본으로 집을 살 때(취득 비용·원리금·보유세·매도 비용·양도세)와 전세 살며 차액을 투자할 때(전세대출 이자·보증보험·2년마다 전세금 상승)의 연도별 순자산을 비교하고 손익분기 집값 상승률을 구합니다.

## 자동차 구매/리스/렌트 · 예금/적금/ISA/연금저축 · 퇴직연금 DC/DB

- **자동차 구매 vs 리스 vs 렌트**: 취득세 7%(전기차 감면), 배기량별 자동차세(차령 경감), 할부 이자, 보험·정비, 잔존가치, 리스 만기 반납/인수, 사업자 비용처리(연 1,500만원 한도)를 반영한 보유 기간 총비용 비교.
- **예금 · 적금 · ISA · 연금저축 세후 비교**: 이자소득세 15.4%, ISA 비과세 500/1,000만(초과 9.9%), 연금저축 세액공제(600만 한도, 16.5/13.2%)와 연금소득세를 반영한 세후 최종 금액과 돈이 묶이는 기간.
- **퇴직연금 DC vs DB · 일시금 vs 연금**: 임금상승률 대비 운용수익률로 DB·DC 퇴직급여를 비교하고 손익분기 수익률을 구합니다. 두 번째 탭은 퇴직소득세 산식과 연금 수령 감면(30/40%)으로 일시금과 IRP 연금 수령의 세금·총수령액을 비교합니다.

## 내 재무 대시보드 · 이직 제안 비교 · 결혼·신혼 자금 플래너

- **내 재무 대시보드**(허브): 자산·부채·소득·지출을 한 번 넣으면 순자산·실수령·저축률·DSR·비상금·연간 세금·보유세·자동차세가 카드로 뜨고 각 계산기로 이어집니다. 입력값은 `localStorage`(`ht_profile`)에 저장되어, 필드에 `p:'키'`를 단 다른 계산기(내 집 마련·1억 만들기·은퇴·전세 비교·DSR·실수령액·이직·결혼)의 초기값으로 자동 전달됩니다. 코어 `HT.profile`과 `HT.form`의 `p` 옵션이 이 구조를 담당합니다.
- **이직 제안 비교**: 현 직장 vs 제안을 실수령(청년 소득세 감면 포함)·퇴직금 적립·성과급(세후)·복지·연차 가치·통근 비용·통근 시간 가치로 환산한 세후 총보상으로 비교합니다.
- **결혼·신혼 자금 플래너**: 두 사람 자산 + 양가 지원(혼인 증여공제 1억 + 기본 5천만, 초과분 증여세) − 결혼 비용 → 신혼집(전세: 신혼부부 버팀목 80%·3억 한도·2026 소득요건 7,500만 / 매수: 취득 비용·주담대) → 월 주거비·부부 DSR → 3년 순자산 흐름.

## 또래 백분위 · 노동시간 가격표 · 국민연금 본전 나이 · 그때 샀더라면

- **나는 상위 몇 %?**: 국세청 2023년 귀속 근로소득 백분위(0.1% 11.38억 · 1% 2.17억 · 10% 1.01억 · 20% 7,624만 · 중위 4,272만), 통계청 임금근로일자리 연령별 평균소득, 2025년 가계금융복지조사 순자산 분위·연령별 평균을 내장해 연봉·순자산의 전체·또래 순위를 로그 보간/로그정규 근사로 추정하고 공유 문장을 만듭니다.
- **노동시간 가격표**: 세후(또는 세전) 시급으로 커피·아이폰·자동차·서울 아파트를 "일해야 하는 시간"으로 환산. 품목 추가 가능.
- **국민연금 본전 나이**: 개혁 일정(9.5%→13%)으로 낼 보험료 총액(본인/전체)과 2026 산식 연금액으로 본전 나이·수익비, 조기·연기 수령 5안 비교와 교차 나이.
- **그때 샀더라면**: 2010~2025 연말 데이터(코스피, S&P 500, 달러, 금, 비트코인, KB 서울 아파트 평균)를 내장해 목돈/매년 투자의 현재 가치를 자산별로 비교하고 예금과 견줍니다. 데이터 표는 화면에서 수정 가능.

## 부모 세대 vs 나 · 평생 세금 총액 · 내 세금이 간 곳 · 돈 성향 16유형 · 퇴사 버튼

- **부모 세대 vs 나**: 부모가 내 나이였던 해와 지금의 서울 아파트 평균가·평균 임금·물가·최저임금을 표(수정 가능)로 내장해 PIR(집값 ÷ 연봉)과 배수를 비교합니다.
- **평생 세금 총액**: 연봉 곡선(인상률·은퇴 나이)에 소득세·4대보험·부가세(지출 과세 비율 추정)·보유세·자동차세를 얹어 기대수명까지의 합계, 서울 아파트 몇 채, 평생 소득 대비 %를 냅니다. 현재 가치 할인 옵션.
- **내 세금이 간 곳**: 소득세 + 부가세(추정)를 2026년 확정 예산(727.9조) 12개 분야 비율로 배분합니다.
- **돈 성향 16유형**: 12문항 4축(모으기/쓰기·안정/도전·계획/즉흥·미래/현재) 자가진단, 유형별 함정과 추천 계산기, 결과 저장·복사.
- **퇴사 버튼**: 비상금·퇴직금·실업급여(비자발 이직만, 2026 상한 68,100/하한 66,048원, 소정급여일수 표)로 몇 개월 버티는지, 건강보험 지역가입 전환 비용, 잔액 추이.

## 글자수 세기 · 나이/D-day · 아이 양육비 · 구독료 · 신년운세 · 타로 · 공유 카드

- **글자수 세기**: 공백 포함/제외, 바이트(한글 2바이트·UTF-8), 단어·문장·줄·원고지, 자소서 한도 초과 표시, 자주 쓴 글자. 입력은 브라우저에 저장.
- **나이 · D-day 계산기**: 만/연/세는 나이, 살아온 날, 10,000일, 다음 생일, 띠·별자리·요일 / D-day·100일·1000일·전역일(군별 복무기간·진급)·출산 예정일(280일, 검사 일정).
- **아이 한 명 키우는 데 얼마**: 나이대별 양육비 + 사교육(2024 조사 참고) + 대학 − 2026 지원(첫만남이용권·부모급여·아동수당·자녀세액공제) = 순부담, 물가 반영·둘째 옵션.
- **구독료 · 습관 지출의 진실**: 구독 18종 체크리스트 + 습관 지출 7종 → 월·연 총액, 30년 복리, 시급 환산, 하나씩 끊었을 때.
- **2027 신년운세(정미년)**: 띠와 未의 합·충·형·해 관계로 기본 등급, 생년월일 해시로 5분야·월별 흐름·행운 요소. **타로 한 장**: 메이저 아르카나 22장 SVG 카드, 정/역방향, 사랑·일·돈·조언 풀이.
- **공유 카드 이미지**: 코어 `HT.shareCard`/`HT.shareButtons`가 결과를 1080×1080 PNG 카드(Tide 색)로 저장합니다. 백분위·16유형·부모 세대·평생 세금·세금 행방·퇴사·노동시간·그때 샀더라면·양육비·구독·신년운세·타로에 적용.
