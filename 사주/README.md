# 사주 풀이

생년월일시를 넣으면 사주 원국을 세우고, 고전 명리의 틀로 풀이하는 웹 페이지입니다.
서버·외부 API 없이 순수 HTML/JS로 동작합니다. `index.html`을 열거나 정적 호스팅에 그대로 올리면 됩니다.

## 실행

```
py -3 -m http.server 8791 --directory 사주
```

`http://localhost:8791/` 접속. 검증 페이지는 `/tools/test.html` (절기 72건·음력 31건·일진·사주 기둥, 총 112건).

## 구성

| 파일 | 역할 |
|---|---|
| `js/astro.js` | 율리우스일, ΔT, 태양 겉보기 황경(VSOP87 축약), 삭(신월) — Meeus, Astronomical Algorithms |
| `js/manse.js` | 24절기(KST), 음력(동지·중기 규칙, 윤달), 간지, 표준시·서머타임 이력, 진태양시 보정, 사주 네 기둥 |
| `js/saju.js` | 십신, 지장간, 12운성, 신살, 합충형파해, 오행 강약(득령·득지·득세), 격국, 억부 용신, 대운·세운 |
| `js/text.js` | 해설문 — 적천수 통신론 원문·풀이, 일주 60, 십신·격국(자평진전)·오행·신살·12운성·대운 해설, 궁통보감 조후 표 |
| `js/app.js` | 입력·렌더링·URL 공유 |
| `css/` | 코웨이엔텍 Tide 토큰 + 앱 스타일 |

## 계산 기준

- 절기: 태양 황경을 직접 계산. 한국천문연구원 공표값(2024·2026·1988)과 1분 이내 일치.
- 음력: 삭 시각과 중기를 KST 날짜로 판정. 2027년 설(2/7, 중국과 다름)·2033년 윤11월 등 확인.
- 연주는 입춘, 월주는 절(節) 기준. 시주는 출생지 경도로 진태양시 보정(서울 −32분), 균시차는 선택.
- 표준시 이력 반영: 1908~1911·1954~1961 UTC+8:30, 서머타임 1948~1960·1987~1988.
- 23시 이후 출생은 기본 다음 날 일주(자시 기준), 야자시 선택 가능.
- 대운수: 생일에서 절기까지 날수 ÷ 3, 반올림. 나이는 만 나이로 표시.
- 오행 비율: 천간 1(월간 1.2), 지지는 지장간 비율(정기 0.6·중기 0.3·여기 0.1) × 자리 가중(년 1·월 2·일 1.5·시 1).

## 유의

해설은 참고용이며 유파에 따라 시간 보정·강약 판정·용신이 달라질 수 있습니다. 해설 문장은 고전의 틀을 따라 새로 쓴 것이고, 현대 술사의 글은 쓰지 않았습니다.
